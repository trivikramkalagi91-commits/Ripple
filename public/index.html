Architecture

Why FalkorDB is the engine for coding agents

Graph Schema
// Nodes represent files with metadata
(:File {path: string, loc: number})

// Edges represent import relationships
(:File)-[:IMPORTS]->(:File)
Cypher Blast Radius
MATCH (b:File {path: $target})
MATCH p = (a:File)-[:IMPORTS*1..4]->(b)
RETURN a.path AS dependent,
      min(length(p)) AS distance
ORDER BY distance ASC

Quickstart

Get graph-aware in three steps

Run FalkorDB locally via Docker. The graph database runs on port 6379 and the interactive browser on port 3000.
docker run -d --name falkordb --restart unless-stopped -p 6379:6379 -p 3000:3000 falkordb/falkordb:latest
Graph DB: localhost:6379 Browser: localhost:3000
Point the indexer at your TypeScript or JavaScript project. Ripple parses the AST, resolves barrel files and aliases, then builds the graph.
# Clone and build Ripple first
git clone https://github.com/trivikramkalagi91-commits/Ripple.git
cd Ripple && npm install && npm run build

# Index your project
node dist/cli.js index /path/to/your/project
Add Ripple to your AI editor's MCP configuration file. Works with Cursor, Claude Desktop, Antigravity IDE, and VS Code.
{
  "mcpServers": {
    "ripple": {
      "command": "node",
      "args": ["/path/to/Ripple/dist/server.js"]
    }
  }
}
